# Perceo workflow

Perceo is organized around a simple loop: prepare context, run the task, review evidence, then fold the result back into the system.

## The loop

1. Capture durable project and team context.
2. Start the right execution surface for the task.
3. Run the agent inside an isolated workspace.
4. Review diffs, checks, comments, and release readiness.
5. Preserve useful outcomes for future work.
