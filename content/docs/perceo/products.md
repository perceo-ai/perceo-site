# Perceo products

Perceo is the suite. The individual products handle the concrete work inside the loop.

## Current public surfaces

::card Archivum docs | Knowledge workspace for notes, project context, decisions, and AI-readable Markdown. | /docs/archivum
::card Archductor docs | Agent execution workbench for branches, worktrees, PTY sessions, checks, reviews, and PRs. | /docs/archductor

## Product pages

::card Archivum product page | Product summary for the knowledge workspace. | /products#archivum
::card Archductor product page | Dedicated product page for the execution workbench. | /products/archductor

## Product responsibilities

- **Perceo** explains the suite-level workflow and how the parts connect.
- **Archivum** keeps the human knowledge layer close to the work.
- **Archductor** gives each task an isolated workspace and a reviewable path to a PR.
