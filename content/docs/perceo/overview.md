# Perceo overview

Perceo is the suite-level product for agentic work: collect the right context, run the work in isolated execution surfaces, and keep enough evidence around to review what changed before it ships.

The public docs currently focus on the pieces that are ready to explain: Archivum for knowledge and Archductor for execution. Locked concepts stay out of the navigation until they are ready.

> Info: Use this page as the suite entry point. Product-specific setup and behavior lives in each product's docs.

## What Perceo coordinates

- Human context from notes, docs, decisions, and operating knowledge.
- Execution context from repositories, branches, workspaces, prompts, checks, and PRs.
- Review context from diffs, terminal output, comments, and release readiness.
